## SonderAssist 9.1

**Wide mode**
- **Mute system sounds**: hides the microphone's beep while it listens. Music keeps playing.
  Off by default.
- **Fewer restarts**: asks the microphone to wait longer before it restarts, so it beeps less
  often. Off by default.
- When a real theft takes over while wide mode is listening, "What it heard" keeps wide
  mode's lines and says the alert took over.
