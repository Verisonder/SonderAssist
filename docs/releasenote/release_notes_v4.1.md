## SonderAssist 4.1

Layout only. Nothing behaves differently.

### The home screen sits down the page

It carries three things and was pressed against the status bar with the rest of the screen
empty below it. It now reads as a block on the screen rather than a list that ran out.

### The tile trail moved

The record of what the quick settings tile last did is a diagnostic, not a status. It
answers whether the tile did anything at all, which is worth keeping and is not worth the
top of the home screen — so it sits with the other diagnostics in settings now.

The home screen is the status, what the detector is doing right now, and sensitivity.
