## SonderAssist 5.5

The strap gets its own message.

A strap alert used to show nothing at all. It can now carry its own words, separate from
the grab message, in a box in the strap section on the main screen.

The default is "Wait for the owner to come back" — a strap alert fires on a Bluetooth drop,
which is a guess about where your watch went rather than a claim that someone has taken the
phone, so it should not accuse whoever reads it.

Leave the box blank and a strap alert shows nothing, exactly as before. It saves as you
type.

No sensitivity thresholds changed. None have changed since 4.4.
