## SonderAssist 9

**Wide mode** — its own page on the home screen, off by default.
- A second, more sensitive grab detector that never locks by itself.
- A lighter grab only opens the microphone. Say "Friday" and theft mode starts, with the
  F.R.I.D.A.Y clip. "Friday 10 seconds" starts the countdown as well.
- Its own sensitivity slider, its own listening time (10 to 300 s), and an optional short buzz
  when it starts listening.
- Music is not muted while it listens.
- What it heard shows on the same page.
