## SonderAssist 8.7

**Control by text** has its own page and its own row on the home screen.

The text commands can now be renamed. The defaults, after your secret word:

- `locate` — replies with the location
- `lock` — locks the screen
- `find` — rings for 30 seconds
- `10sec` — any number of seconds, then the siren
- `friday` — plays the F.R.I.D.A.Y clip (leave it empty to turn it off)
- `help` — lists the commands

**F.R.I.D.A.Y**: the screen stays on while the countdown runs, and turns on if it was
off, so the countdown can be watched to the end.
