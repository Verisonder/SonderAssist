## SonderAssist 5.6

The message types itself out.

Both alert screens — the J.A.R.V.I.S one and the plain one — now write the message a letter
at a time, with a block following the last letter. The block disappears on the final
character rather than sitting there blinking.

It applies to both messages, the grab one and the strap one.

One slider controls it, just above the message box: nought to 150 milliseconds a letter, 45
by default. Drag it to nought and the message appears all at once, exactly as it did before.

The alert screen is destroyed and rebuilt whenever it comes back — after being covered, or
after the home gesture — so it retypes from the start each time.
